# Placeholders

Some values in this repository are environment-specific and were replaced with placeholders.
Replace them with your own values before installing.

| Placeholder | Replace with |
|---|---|
| `<your-host>` | hostname of your main workstation |
| `ACME` | example customer/project name (was an internal project) |
| `Ayaz-in-the-house` | maintainer handle |
| `FieldApp` | example field-operations app name |
| `Globex` | example customer name |
| `Springfield` | example region name |
| `acme` | example customer/project name (lowercase) |
| `ayaz-in-the-house` | maintainer handle (lowercase) |
| `globex` | example customer name (lowercase) |
| `initech` | example customer name (lowercase) |
| `private-project-N` — a private companion project of the original author; not part of this repository | ×27 |
| documentation address `192.0.2.x` (RFC 5737) — use your own host/Tailscale IP | ×8 |
